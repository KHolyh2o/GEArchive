아카이브 관리 가이드

← 관리 화면

졸업전시 아카이브에 새 전시를 올리거나 고치는 방법입니다. 처음 쓰는 사람도 이 페이지만 보면 됩니다.

누가 쓸 수 있나요 로그인 전시 추가 수정·삭제 파일 규격 도록 용량 줄이기 학과 정보 화면 표시 규칙 문제 해결

누가 쓸 수 있나요

별도 가입이나 계정 발급은 없습니다. 미디어콘텐츠학부 서버(media.seowon.ac.kr)에 관리자(sudo) 권한이 있는 계정만 로그인할 수 있습니다.

  • 아이디/비밀번호는 서버에 접속할 때 쓰는 서버 계정과 같습니다.
  • 서버 계정이 있어도 관리자(sudo) 권한이 없으면 로그인되지 않습니다.
  • 권한이 필요하면 서버 관리자에게 sudo 그룹 추가를 요청하세요.
  • 관리자 비밀번호가 바뀌면 이 페이지에서도 새 비밀번호로 로그인하면 됩니다.

로그인

  1. https://media.seowon.ac.kr/admin/ 에 접속합니다.
  2. 서버 아이디와 비밀번호를 입력합니다.
  3. 로그인되면 전시 목록이 보입니다. 8시간 뒤에는 자동으로 로그아웃됩니다.
주의 비밀번호를 5번 틀리면 15분 동안 로그인이 막힙니다. 공용 컴퓨터에서는 작업이 끝나면 꼭 로그아웃하세요.

새 전시 추가하기 (예: 2027년 졸업전시)

  1. 아래쪽 전시 추가 / 수정 칸을 채웁니다.
  2. 연도(예: 2027)와 전시 제목은 꼭 입력해야 합니다.
  3. 전시 시작일·종료일을 달력에서 고릅니다. 하루만 하면 시작일만 넣어도 됩니다.
  4. 전시 사이트 주소(예: https://media.seowon.ac.kr/2027/)를 넣습니다. 카드를 누르면 이 주소로 이동합니다.
  5. 포스터 이미지와 도록 PDF를 선택합니다. 아직 없으면 비워 두고 나중에 올려도 됩니다.
  6. 저장을 누르면 끝입니다. 아카이브 페이지에 바로 반영됩니다.
참고 저장 후 별도의 배포나 대기 시간은 없습니다. 아카이브 페이지를 새로고침하면 보입니다.

수정·삭제하기

수정

  1. 목록에서 해당 전시의 수정을 누르면 아래 입력칸에 기존 내용이 채워집니다.
  2. 바꿀 내용만 고치고 저장합니다. 같은 연도를 입력하면 새로 추가되지 않고 기존 전시가 수정됩니다.
  3. 파일을 새로 고르지 않으면 기존 포스터·도록이 그대로 유지됩니다.
  4. 포스터를 없애려면 기존 포스터 삭제를 체크하고 저장합니다. 그러면 색 그라데이션 카드로 바뀝니다.

삭제

  • 목록의 삭제를 누르면 아카이브 페이지에서 그 전시가 사라집니다.
  • 업로드했던 포스터·도록 파일은 서버에 남아 있습니다. 실수로 지웠다면 같은 연도로 다시 추가하세요.

파일 규격

포스터PNG, JPG, WEBP 이미지. 세로형(예: A1·A2 비율)을 권장합니다. 원본 비율 그대로 카드에 표시됩니다.
도록PDF 파일만 가능합니다. 최대 300MB(150MB 안팎 권장). 용량이 크면 줄이는 방법을 보세요.
저장되는 이름자동으로 2027_poster.png, 2027_catalog.pdf 처럼 연도별로 정리됩니다. 파일 이름은 신경 쓰지 않아도 됩니다.
주의 파일의 실제 내용으로 종류를 확인합니다. 이름만 .pdf로 바꾼 다른 파일은 거부됩니다.

도록 PDF가 너무 클 때 (용량 줄이기)

인디자인에서 그대로 내보낸 도록은 수백 MB가 되기 쉽습니다. 2026 도록은 약 773MB → 약 141MB(171쪽, 약 30초)로 줄였고, 화면에서 원본과 거의 구분되지 않았습니다. 업로드 한도는 300MB이고, 방문자가 내려받는 것을 생각하면 150MB 안팎을 권장합니다.

방법 1. 무료 도구(Ghostscript)로 줄이기 (추천)

원본은 그대로 두고, 같은 폴더에 도록_압축.pdf를 새로 만듭니다. 처음 한 번만 설치하면 다음부터는 3번만 하면 됩니다.

Windows

  1. 설치 (처음 한 번) — ghostscript.com/releases/gsdnld.html에서 Windows용(64bit)을 받아 설치합니다. 또는 명령 프롬프트에서 아래를 실행해도 됩니다. 
    winget install ArtifexSoftware.GhostScript
  2. 도록 PDF가 있는 폴더에서 명령 프롬프트 열기 — 아래 두 방법 중 편한 것을 고르세요.

    방법 A. 탐색기에서 바로 열기 (가장 쉬움)

    1. 파일 탐색기에서 도록 PDF가 들어 있는 폴더를 엽니다.
    2. 창 맨 위의 주소창(폴더 경로가 적힌 곳)의 빈 곳을 한 번 클릭합니다. 경로가 파랗게 선택됩니다.
    3. 그 상태에서 글자를 모두 지우고 cmd라고 입력한 뒤 Enter를 누릅니다.
    4. 까만 창이 열리고, 줄 맨 앞에 C:\...\폴더이름>처럼 그 폴더 경로가 보이면 성공입니다.

    방법 B. 이미 열려 있는 PowerShell/명령 프롬프트에서 이동하기

    1. 탐색기에서 도록 폴더를 열고 주소창을 클릭한 뒤 Ctrl+C로 경로를 복사합니다.
    2. 까만 창에 cd /d "까지 입력하고(cd 뒤에 띄어쓰기, /d, 띄어쓰기, 따옴표) 마우스 오른쪽 버튼(또는 Ctrl+V)으로 경로를 붙여넣은 뒤 따옴표를 닫고 Enter를 누릅니다. 
      cd /d "D:\2026 졸업전시\도록"
    3. /d는 다른 드라이브(C: → D: 등)로도 이동하게 해 주는 옵션입니다. 경로에 띄어쓰기나 한글이 있어도 따옴표로 감싸면 됩니다.
    4. PowerShell(줄 앞에 PS가 붙어 있음)을 쓰고 있다면 이동한 뒤 cmd를 입력하고 Enter를 누르세요. 줄 앞의 PS가 사라지면 명령 프롬프트로 바뀐 것입니다.

    제대로 왔는지 확인 — 아래를 입력해서 도록.pdf가 목록에 보이면 맞는 폴더입니다. 안 보이면 폴더를 잘못 온 것이니 위 과정을 다시 하세요.

    dir *.pdf
  3. 실행 — 아래 한 줄을 그대로 붙여넣고 Enter를 누릅니다. 파일 이름이 도록.pdf가 아니면 마지막 이름만 바꿉니다. 끝날 때까지 수십 초 걸리며, 아무 글자도 안 나오다가 줄이 다시 나타나면 끝난 것입니다. 
    gswin64c -q -dNOPAUSE -dBATCH -sDEVICE=pdfwrite -dCompatibilityLevel=1.6 -dPDFSETTINGS=/ebook -dColorConversionStrategy=/LeaveColorUnchanged -dDetectDuplicateImages=true -dDownsampleColorImages=true -dColorImageDownsampleType=/Bicubic -dColorImageDownsampleThreshold=1.0 -dColorImageResolution=275 -dDownsampleGrayImages=true -dGrayImageDownsampleThreshold=1.0 -dGrayImageResolution=275 -sOutputFile=도록_압축.pdf 도록.pdf
  4. 확인 — dir *.pdf를 다시 입력해 도록_압축.pdf가 생겼는지, 용량이 크게 줄었는지 봅니다. 파일을 열어서 글자와 사진이 괜찮은지 확인한 뒤, 관리 화면의 도록 (PDF)에 올립니다.

"'gswin64c'은(는) 내부 또는 외부 명령...이 아닙니다"라고 나오면 설치 경로가 등록되지 않은 것입니다. gswin64c 대신 전체 경로를 쓰세요. 버전 숫자는 C:\Program Files\gs 폴더 안에서 확인합니다.

"C:\Program Files\gs\gs10.08.0\bin\gswin64c.exe" -q -dNOPAUSE ... (나머지는 위와 동일)

맥

  1. 설치 (처음 한 번) — 터미널 앱(Spotlight ⌘+Space → "터미널")을 열고 실행합니다. 
    brew install ghostscript
  2. 도록 PDF가 있는 폴더로 이동하기 — 아래 두 방법 중 편한 것을 고르세요.

    방법 A. 폴더를 끌어다 놓기 (가장 쉬움)

    1. 터미널에 cd와 띄어쓰기 한 칸만 입력합니다. (아직 Enter는 누르지 않습니다.)
    2. Finder에서 도록 PDF가 들어 있는 폴더를 마우스로 끌어서 터미널 창 위에 놓습니다. 폴더 경로가 자동으로 입력됩니다.
    3. Enter를 누릅니다.

    방법 B. 경로를 직접 입력하기

    1. 다운로드 폴더에 있다면 아래처럼 입력합니다. cd는 "폴더 이동"이고 ~는 내 홈 폴더입니다. 
      cd ~/Downloads
    2. 그 안의 다른 폴더로 들어가려면 이름을 이어서 씁니다. (예: cd ~/Downloads/도록) 폴더 이름에 띄어쓰기가 있으면 방법 A가 안전합니다.

    제대로 왔는지 확인 — 아래를 입력해서 도록.pdf가 목록에 보이면 맞는 폴더입니다.

    ls *.pdf
  3. 실행 — 아래를 붙여넣고 Enter를 누릅니다. 끝날 때까지 수십 초 걸리며, 아무 글자도 안 나오다가 줄이 다시 나타나면 끝난 것입니다. 
    gs -q -dNOPAUSE -dBATCH -sDEVICE=pdfwrite -dCompatibilityLevel=1.6 \
  -dPDFSETTINGS=/ebook -dColorConversionStrategy=/LeaveColorUnchanged \
  -dDetectDuplicateImages=true \
  -dDownsampleColorImages=true -dColorImageDownsampleType=/Bicubic \
  -dColorImageDownsampleThreshold=1.0 -dColorImageResolution=275 \
  -dDownsampleGrayImages=true -dGrayImageDownsampleThreshold=1.0 \
  -dGrayImageResolution=275 \
  -sOutputFile=도록_압축.pdf 도록.pdf
  4. 확인 — ls -lh *.pdf로 도록_압축.pdf가 생겼고 용량이 크게 줄었는지 봅니다. 파일을 열어 글자와 사진을 확인한 뒤 관리 화면에 올립니다.

방법 2. 인디자인에서 처음부터 작게 내보내기

내보내기 → Adobe PDF에서 프리셋을 최소 파일 크기로 고르면 비슷하게 줄어듭니다.

주의 -dColorConversionStrategy=/LeaveColorUnchanged 옵션을 빼면 투명 효과가 많은 인디자인 PDF에서 오류가 나고 빈 파일이 만들어질 수 있습니다. 압축 후에는 용량(수 KB면 실패)과 쪽수를 꼭 확인하세요.
화질과 용량 숫자 275가 사진·이미지의 해상도(dpi)입니다. 클수록 선명하고 용량이 커집니다. 글자가 이미지로 들어간 쪽이 흐리게 보이면 275를 300으로, 용량이 너무 크면 225로 바꿔 보세요. (2026 도록 기준: 225 → 약 103MB, 275 → 약 141MB) 인쇄용 원본은 따로 보관하고, 웹에는 압축본만 올리세요.

학과 정보

관리 화면 맨 아래 학과 정보에서 학과 홈페이지, Instagram, 주소, 전화번호, 다음 졸업전시 예정일을 바꿀 수 있습니다. 바꾼 뒤 학과 정보 저장을 눌러야 반영됩니다.

페이지 맨 아래 푸터의 주소·연락처는 이 칸과 별개로 고정돼 있습니다. 푸터를 바꾸려면 개발자에게 문의하세요.

아카이브 화면에는 어떻게 보이나요

THIS YEAR올해 연도의 전시를 보여줍니다. 올해 전시가 없으면 가장 최근 전시를 LATEST로 보여줍니다.
NEXT아직 끝나지 않은 가장 가까운 전시의 날짜가 자동으로 표시됩니다. 해당하는 전시가 없으면 학과 정보의 "다음 졸업전시 예정일"이 표시됩니다.
카드의 전시 기간카드에 마우스를 올리면 제목과 함께 시작일~종료일이 보입니다.
포스터가 없을 때연도와 제목이 적힌 색 그라데이션 카드로 표시됩니다.

문제 해결

로그인이 안 돼요

  • 서버 계정의 아이디/비밀번호가 맞는지 확인하세요. 학교 포털 비밀번호와는 다를 수 있습니다.
  • 관리자(sudo) 권한이 없는 계정이면 비밀번호가 맞아도 거부됩니다.
  • 5번 틀렸다면 15분 뒤에 다시 시도하세요.

저장했는데 아카이브에 안 보여요

  • 아카이브 페이지를 새로고침하세요(안 되면 ⌘⇧R / Ctrl+Shift+R).
  • 저장 후 "저장되었습니다" 메시지가 떴는지 확인하세요. 오류 메시지가 빨간색으로 나왔다면 그 안내대로 고치면 됩니다.

"파일이 너무 큽니다" 라고 나와요

도록 PDF가 300MB를 넘는 경우입니다. 도록 PDF 용량 줄이기대로 압축해서 다시 올려 주세요.

갑자기 로그인 화면으로 돌아갔어요

로그인 후 8시간이 지났거나 서버가 다시 시작된 경우입니다. 다시 로그인하세요. 입력하던 내용은 저장되지 않으니 긴 작업은 중간에 저장하세요.

그래도 안 되면 개발자에게 화면의 오류 메시지를 캡처해서 전달해 주세요.
